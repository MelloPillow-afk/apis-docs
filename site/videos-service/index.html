Pilgrims Videos Service API

Version 1.0.0

Manage videos, upload media, track processing jobs, publish videos, and find playback links. Admin endpoints live under /admin; any authenticated caller has admin access for the MVP. Viewers see ready, published videos. Job status is public at /jobs/{job_id}, so clients can poll processing progress after completing an upload. Viewer access may require authentication, depending on the service settings. JSON fields use snake_case. IDs are UUIDs and timestamps use UTC. Unavailable values are null. Previously shared playback links may remain accessible for a time after a video is unpublished or deleted.

Base URL

$BASE_URL/v1. Set BASE_URL to the API host. The examples below use it as written.

Authentication

Bearer token for authentication.

-H "Authorization: Bearer $TOKEN"

Each endpoint states whether it needs the token.

Errors

A deliberate HTTP error raised by the application.

{
  "detail": "The video was not found."
}

Each endpoint lists the error statuses it can return.
